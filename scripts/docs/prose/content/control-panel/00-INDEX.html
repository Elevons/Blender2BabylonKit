Project Control Panel — Documentation

The Project Control Panel (tools/project-control-panel/, npm workspace @bjs/project-control-panel) is the self-hosted web hub for one project. Each project runs its own Project Control Panel. It starts and stops the project Vite dev server, runs the packaged bjs-mcp behavior-authoring server for Cursor, browses JSON asset folders, serves the bundled documentation, and publishes web builds.

It does not embed Babylon.js editors. Author GUI, materials, particles, and similar assets with the online Babylon editors or your own workflow, then place the exported .json files in the project's asset folders (see Projects & assets).

Quick start

From the kit repo root:

npm install
npm start

From an installed project (the folder that contains game/):

npx b2bkit-control-panel

Open http://localhost:3200 (override with CONTROL_PANEL_PORT).

Production build (serves the compiled React client from dist/client/):

npm run control-panel:build
npm run control-panel:start
