Common mistakes (silent or confusing failures)

  • MESH-shaped triggers never fire — use box/sphere/convex for triggers. Validator warns.
  • Skinned mesh object — put GUID, animation, and scripts on the armature, not the mesh. Validator warns.
  • MESH collider + DYNAMIC body — not supported. Validator warns.
  • AREA lights — not exported to glTF. Use SUN/POINT/SPOT.
  • Hook names must be PascalCase — OnStart, not onStart, or they never run.
  • GUID matching needs ExtrasAsMetadata — the loader imports this glTF extension. Without it, entities fail to match nodes.
  • Paint masks need COLOR_1+ — stock Babylon drops glTF COLOR_1+. LevelLoader registers bjs_extra_vertex_colors. Blender may invent an all-white COLOR_0 and put real paint in COLOR_1. See populateprefabs.ts and Prefabs.
  • Right-handed glTF import — required for correct collider orientation (why).
  • 3D GUI button content — text/images must be applied after the control is added to a panel (11 — UI).
