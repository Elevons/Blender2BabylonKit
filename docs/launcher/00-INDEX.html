Babylon Launcher — Documentation

The Babylon Launcher (tools/babylon-launcher/, npm package @bjs/babylon-launcher) is a local web hub for one game project at a time. It starts that project's Vite server, manages bjs-mcp, browses level assets, edits level include/boot settings, and runs publish builds for web, desktop, and Android.

The hub does not embed Babylon.js editors. Author GUI, materials, and particles in the online Babylon editors, then place the .json files in the project's asset folders.

Quick start

From the repo root, bind the hub to one app:

npm install
npm run hub -- --app playground

Open http://localhost:3200. The hub starts the game's Vite server (default port 5173). Override the hub port with LAUNCHER_PORT.

You can also resolve the project from the environment or the current directory:

  • --app <name> — monorepo app under apps/<name>/
  • BJS_PROJECT_DIR — absolute path to a folder that contains babylon-project.json
  • Working directory — walk up until babylon-project.json is found

Convention: run one hub at a time. The Blender add-on opens http://localhost:3200.

Production build of the hub itself:

npm run launcher:build
npm run hub -- --app playground
# or: npm run launcher:start -- --app playground
