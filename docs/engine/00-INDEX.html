What the runtime does

b2bkit (packages/engine/) loads the two artifacts Blender exports. These are level.glb (everything glTF can express) and level.scene.json (everything glTF cannot express). The loader turns them into a live Level. LevelLoader.Load appends the glb. It indexes nodes by GUID. It builds an Entity per manifest entry. It applies components through small subsystems (physics, lights, cameras, audio, …). Then it runs your Behavior scripts.

Regenerating

npm run docs:build regenerates both sides from the shared shell template (docs/_template/diagram-shell.html). It also rebuilds the searchable landing page. npm run docs:trace rebuilds only this folder. It re-extracts every trace's source from packages/engine/. A renamed or deleted symbol fails the build loudly. This is the anti-rot guard. The Blender side alone uses npm run docs:blender.
